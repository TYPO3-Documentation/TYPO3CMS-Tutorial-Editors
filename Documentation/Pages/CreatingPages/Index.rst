==============
Creating pages
==============

Pages form the core structure of your website. Here you will learn
how to **add pages to your site** using the page tree in the middle pane. Then you will
learn how to **publish your new page**.

..  youtube:: UzHc1Z3vT6E

------------

There are two ways to add a page. You can either **drag and drop from icons**
above the page tree or **right click on the tree** to bring up a context menu.
In both methods you select an existing page in the tree and your new page is
created underneath.

Don't worry about perfect positioning. You can always move pages around later
by dragging and dropping them to a new spot in the tree.

Here we will create a normal web page (called a **standard** page). First open
the :guilabel:`Content > Layout` module in the left sidebar. The
page tree is in the middle. Click around the page tree to see the selected page
displayed in the right pane.

..  _pages-creating-tree:

Method 1: Using drag and drop
=============================

..  figure:: /Images/ManualScreenshots/PageTree/PageCreateDragDrop.png
    :alt: Creating a page using drag and drop
    :zoom: gallery

    Create a standard page using drag-and-drop

#.  Open the **page creator**: Click the :guilabel:`+ Page` button at the top left
    of the page tree, or find the **row of icons** representing different types
    of pages.

#.  Position your page:

    *   If using :guilabel:`+ Page`: Click the button and select an existing page
        from the popup window and click :guilabel:`Insert subpage`. Choose the
        standard page type.
    *   If dragging an icon: Grab the **Standard Page** icon and drag it
        into the page tree. Drop it onto an existing page.

#.  Name your page: Enter a title in the popup window.

..  figure:: /Images/ManualScreenshots/PageTree/PageCreateTitle.png
    :alt: Inserting a page title
    :zoom: gallery

    Adding page title "Page 4" in the popup window

..  _pages-creating-context:

Method 2: Using the context menu
================================

#.  Right click an existing page in your page tree.
#.  Select :guilabel:`New subpage` from the context menu (see below).
#.  Fill out the page title in the popup window.

..  figure:: /Images/ManualScreenshots/PageTree/PageCreateContextMenu.png
    :alt: Creating pages with the context menu
    :zoom: gallery

    Creating pages with the context menu

Check :ref:`page types <pages-types>` if you want to find out more about the
types of pages that you can create in TYPO3.

..  _pages-publishing:

Publishing your new web page
============================

New pages are created as drafts and hidden from the public by default. When you
are ready, you can publish your page in 3 different ways:

*   From the page tree: Right-click the page name and toggle the
    :guilabel:`Enable` switch from the context menu.
*   From the page properties of a page: Click on the page, click on
    :guilabel:`Edit page properties` at the top of the main pane, click on
    the :guilabel:`Access` tab, and toggle the :guilabel:`Page visible` switch
    (see below).
*   You can also publish while you are creating a page: Scroll to the bottom of
    the popup window and toggle the :guilabel:`Enable` switch.
