===========================================================
Change your password and set up multi-factor authentication
===========================================================

Change your password and set up a second login factor here.

*   **New password:** Your new password. How strong it has to be is set by
    your installation.
*   **Multi-factor authentication:** An extra factor, for example a one-time
    code, that is asked for after your password. Use
    :guilabel:`Setup multi-factor authentication` to switch it on.
